# Landfall documentation

Landfall 0.4.2 creates static map images from coordinates, GeoJSON, Shapely
geometries, and GeoDataFrames. Start with [getting started](getting-started.md)
if you are making your first map, then use the guide that matches your data.

![Three points plotted on a map of Tampa Bay](images/points.png)

| Guide | Use it for |
| --- | --- |
| [Getting started](getting-started.md) | Install, coordinate order, first image, output formats |
| [Shapes and styling](shapes-and-styling.md) | Points, routes, polygons, circles, colors, groups, layers |
| [Geospatial data](geospatial-data.md) | GeoJSON, Shapely, GeoPandas, coordinate systems |
| [API reference](api.md) | Function selection, signatures, defaults, shared options |
| [Troubleshooting](troubleshooting.md) | Tile, dependency, input, and rendering problems |
| [Contributing](contributing.md) | Development setup and release checks |

Runnable notebook examples are available for
[points](https://github.com/eddiethedean/landfall/blob/main/examples/plot_points_function.ipynb),
[lines](https://github.com/eddiethedean/landfall/blob/main/examples/plot_lines_function.ipynb), and
[polygons](https://github.com/eddiethedean/landfall/blob/main/examples/plot_polygons_function.ipynb).
These notebooks render real map tiles and need network access.

See the [repository README](https://github.com/eddiethedean/landfall#readme)
for a quick example and the
[changelog](https://github.com/eddiethedean/landfall/blob/main/CHANGELOG.md)
for release history.
